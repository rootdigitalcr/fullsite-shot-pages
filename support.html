Support

Report problems and questions through the public project tracker. This repository does not contain the extension source code.

Open a support request on GitHub

In the extension

After install, right-click the FullSite Shot icon and open Help. That guide covers capture, annotations, export, and limits. Privacy and Scope and limitations are in the same menu and in the viewer footer. Captures are temporary: copy or export before you close the viewer tab. Chrome can ask for confirmation on the way out if you have used the viewer and have not yet copied or downloaded PNG or PDF.

Quick use

  1. Open a normal http or https page (not chrome:// and not the Chrome Web Store).
  2. Click the FullSite Shot icon, or press Alt+Shift+S if the shortcut is assigned.
  3. Wait until a viewer tab opens with the stitched page.
  4. Use Hand, Pen, and Eraser if you want, then Copy or download PNG/PDF.

Before reporting

Include the FullSite Shot and Chrome versions, operating system, the page you tried to capture if you can share it, steps, and expected result. Do not send captures that contain personal data, passwords, tokens, or personal file paths. Support requests are public.

The in-extension “Support the project” link opens Ko-fi only after a voluntary click. Ko-fi is not the support channel for this product.
