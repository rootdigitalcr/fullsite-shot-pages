Privacy Policy

FullSite Shot captures the active tab only after an explicit action from you (toolbar icon or keyboard shortcut). There is no background capture and no monitoring of your browsing.

Only when you ask. The process starts when you click the icon or shortcut, and it finishes in your Chrome.

Information handled

After you start a capture, FullSite Shot takes on-screen tiles of the active tab (images of website content) and stitches them into one PNG in memory. The viewer lets you annotate, copy, or export that image. Annotations exist only in that tab.

FullSite Shot does not keep a library of captures. It does not store the page URL, title, or capture date.

Where it is stored

The capture and annotations live only in the memory of the open viewer tab. Reloading or closing that tab discards them. They are not written to IndexedDB, chrome.storage.local, chrome.storage.sync, or any other persistent store.

Interface language and theme live in chrome.storage.local. While a capture is running, chrome.storage.session keeps only the tab id and a start time so the page can be restored if Chrome interrupts the worker; session storage never holds images, URLs, or titles.

Nothing in that processing is sent to Root Digital CR, to analytics, or to third parties.

What is not collected

There is no analytics, advertising, tracking, telemetry, or accounts. FullSite Shot does not use remote code, CDNs, or runtime-downloaded scripts. Root Digital CR does not receive screenshots, page content, URLs, titles, or annotations.

Permissions

activeTab. Identifies the visible tab when you start a capture. It does not grant ongoing access to other sites.

scripting. Injects a short script into that tab to measure it, scroll it, and freeze fixed elements during capture. The effect is removed when finished.

storage. Stores the interface language and theme in this profile. While a capture is in progress, chrome.storage.session also stores only that tab’s id and a start time so the page can be put back if Chrome interrupts the process. It does not include the image, URL, or title.

contextMenus. Adds Help and Settings to the extension icon menu.

External services

Optional outbound links (Root Digital CR, more extensions, or the voluntary Ko-fi “Support the project” button) open only after an explicit click. They do not include captures, URLs, annotations, or preferences. Ko-fi, if you open it, may handle IP, cookies, or payment data under its own policy; the extension does not receive the payment result.

If you voluntarily open a support request, GitHub processes the information you submit under its own terms. Support requests are public. FullSite Shot never attaches captures or preferences automatically.

Deletion

Closing or reloading the viewer discards the capture and annotations. Uninstalling FullSite Shot or clearing the extension’s site data in Chrome removes language and theme preferences. Copy and download are your actions: those files stay where you saved them or on the clipboard.

Limited Use disclosure

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide the capture, viewer, annotation, and export features; it is not sold or transferred for advertising, profiling, or unrelated purposes, and it is not made available for human reading through developer systems.

Security and changes

FullSite Shot includes no analytics, advertising, remote executable code, or runtime CDN dependencies. Material changes to this policy will update the date on this page.
