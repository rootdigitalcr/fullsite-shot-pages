Scope and limitations

FullSite Shot is built for ordinary web pages, including pages much taller than the screen. Chrome or the page’s own structure can still limit the result.

Embedded content

What appears on screen is captured. If an embedded video, map, form, document, or other page has its own scroll area, content hidden inside that area may not be included. When that content fills almost the whole tab, FullSite Shot tries to walk it.

Inner panels and lists

If a table, list, or panel is essentially the whole page, the extension tries to capture it fully. A small panel inside a larger page is captured as it appears; its hidden overflow may be omitted.

Pages that load forever

Sites that keep loading as you scroll are stopped at a safety limit so a capture cannot run indefinitely.

Very large pages

Chrome has practical image-size limits. An exceptionally large page may be scaled down proportionally so it still fits in one image. Content is not stretched. If it still exceeds the safety limit, capture stops.

PDF files

Chrome’s built-in PDF viewer is not a normal web page. FullSite Shot can show what is on screen; it is not designed to turn a full PDF into one continuous capture.

Local files and protected pages

Local HTML requires “Allow access to file URLs” in the extension details. Chrome blocks chrome://, the Chrome Web Store, and other internal pages.

Content that keeps changing

Videos, GIFs, live charts, or other moving elements may show different moments in different stretches of the capture.

If something goes wrong

If a tile fails, the capture is aborted rather than delivering a damaged image without warning. The extension tries to restore the page to the state it had before capture started.

Incognito requires enabling the extension for that mode in Chrome. Developer-tools device emulation is not guaranteed.
