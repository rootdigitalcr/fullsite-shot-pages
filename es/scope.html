Alcance y limitaciones

FullSite Shot está pensado para páginas web normales, incluidas las mucho más altas que la pantalla. Chrome o la propia estructura de la página pueden limitar el resultado.

Contenido incrustado

Se captura lo que aparece en pantalla. Si un vídeo, mapa, formulario, documento u otra página incrustada tiene su propio desplazamiento, el contenido oculto dentro de esa zona puede no incluirse. Cuando ese contenido ocupa casi toda la pestaña, FullSite Shot intenta recorrerlo.

Paneles internos y listas

Si una tabla, lista o panel es básicamente toda la página, la extensión intenta capturarlo por completo. Un panel pequeño dentro de una página más grande se captura tal como se ve; su desbordamiento oculto puede omitirse.

Páginas que cargan sin fin

Los sitios que siguen cargando al desplazarte se detienen en un límite de seguridad para que una captura no corra indefinidamente.

Páginas muy grandes

Chrome tiene límites prácticos de tamaño de imagen. Una página excepcionalmente grande puede reducirse de forma proporcional para que quepa en una sola imagen. El contenido no se estira. Si aún supera el límite de seguridad, la captura se detiene.

Archivos PDF

El visor de PDF de Chrome no es una página web normal. FullSite Shot puede mostrar lo que hay en pantalla; no está diseñado para convertir un PDF completo en una captura continua.

Archivos locales y páginas protegidas

El HTML local requiere «Permitir el acceso a URL de archivo» en los detalles de la extensión. Chrome bloquea chrome://, Chrome Web Store y otras páginas internas.

Contenido que sigue cambiando

Vídeos, GIFs, gráficos en vivo u otros elementos en movimiento pueden mostrar momentos distintos en tramos distintos de la captura.

Si algo falla

Si una tesela falla, la captura se aborta en lugar de entregar una imagen dañada sin aviso. La extensión intenta devolver la página al estado que tenía antes de empezar.

Incógnito requiere habilitar la extensión para ese modo en Chrome. La emulación de dispositivo de las herramientas de desarrollador no está garantizada.
